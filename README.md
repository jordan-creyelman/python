# Python — Contexte de développement

Ce dépôt centralise les conventions et instructions réutilisables pour les futurs projets Python.

## Documents

- [CONTEXT.md](CONTEXT.md) : principes techniques, structure de projet, qualité et sécurité.
- [AGENTS.md](AGENTS.md) : instructions pour les assistants IA de développement.

## Utilisation

1. Au démarrage d'un nouveau projet, consulter `CONTEXT.md`.
2. Copier ou adapter `AGENTS.md` dans le nouveau dépôt pour guider l'assistant IA.
3. Choisir les bibliothèques et la structure selon les besoins réels du projet.
4. Mettre à jour la documentation quand une décision technique importante est prise.

Ce dépôt contient des **recommandations par défaut** et non un squelette obligatoire. Les contraintes spécifiques d'un projet priment sur les conventions générales.
